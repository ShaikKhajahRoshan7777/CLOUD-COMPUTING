--- 3. Attack simulations ---
forged signature          : 401 UNAUTHENTICATED - signature mismatch (token tampered)
role changed to admin     : 401 UNAUTHENTICATED - signature mismatch (token tampered)
garbage token             : 401 UNAUTHENTICATED - malformed token
expired token (after 2s)  : 401 UNAUTHENTICATED - token expired

--- 4. Secure vs insecure comparison ---
INSECURE: plain-text password, no expiry, no role check  -> any leaked credential = full access
SECURE  : salted hash + signed expiring token + RBAC     -> leak is limited in time and in scope
